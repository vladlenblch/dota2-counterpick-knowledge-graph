# Source availability and field mapping

Checked against live endpoints on 2026-10-07. This file records the actual fields used by the pipeline; it is not a list of assumed API capabilities.

| Source | Verified endpoint / page | Available | Limitation |
| --- | --- | --- | --- |
| Valve | [`herolist`](https://www.dota2.com/datafeed/herolist?language=english), [`herodata`](https://www.dota2.com/datafeed/herodata?hero_id=12&language=english) | Current hero IDs, stats, facets, abilities, special values | `herolist` has identity only; full stats require each `herodata`. Behavior and dispellability are retained as raw codes. `immunity=3` is provisionally interpreted as piercing based on current Valve records for Berserker's Call, Black Hole, Duel, and Fiend's Grip; the code is retained for audit. |
| Valve | [`itemlist`](https://www.dota2.com/datafeed/itemlist?language=english), [`itemdata`](https://www.dota2.com/datafeed/itemdata?item_id=1&language=english), [`abilitylist`](https://www.dota2.com/datafeed/abilitylist?language=english) | Listed item IDs, names, costs, item ability fields; global ability list for audit | The lists can contain internal or unavailable items/abilities. Named listed items are retained with `is_purchasable` and `is_neutral` flags. |
| OpenDota | [`heroStats`](https://api.opendota.com/api/heroStats), [`heroes`](https://api.opendota.com/api/heroes) | Recent rank-bracket pick/win counts, professional pick/win/ban counts | No denominator for overall pick or ban rate; these fields remain null. `constants/rank_tier` returned 404; bracket codes are retained as source codes, not invented names. |
| OpenDota | [`matchups`](https://api.opendota.com/api/heroes/1/matchups), [`itemPopularity`](https://api.opendota.com/api/heroes/1/itemPopularity), [`constants`](https://api.opendota.com/api/constants/items) | Directional games played/wins against opponents; four item phases and usage counts; mapping constants | Item popularity gives counts, not an overall usage denominator. Matchup baseline uses aggregate rank wins/picks from `heroStats`; source windows can differ, so the derived advantage is explicitly approximate. |
| STRATZ | [`GraphQL`](https://api.stratz.com/graphql), [API entry](https://stratz.com/api) | Requires a Bearer token even for schema introspection | A local token was provided, but requests still returned HTTP 403, including a Cloudflare challenge. No automated access-control bypass is attempted. No positions, matchups, synergy, or item observations are inferred. Schema discovery is implemented; statistical queries await accessible schema verification. |
| Dotabuff | [Phantom Lancer counters](https://www.dotabuff.com/heroes/phantom-lancer/counters), [Axe counters](https://www.dotabuff.com/heroes/axe/counters) | Public rendered pages label the page hero's `Disadvantage`, its own win rate, and matches played | Direct script fetch returned HTTP 403. Only manually saved HTML is parsed. The displayed `Disadvantage` sign is inverted for canonical `normalized_advantage`. No wins are fabricated from rounded rates. |

Valve and OpenDota raw snapshots, plus `data/final/` and `data/reports/`, are committed as current outputs. Manually saved Dotabuff HTML remains local and ignored until its contents can be reviewed. Source snapshots are replaced on a complete rerun; no patch tables or versioned entity records are created. If a source is unavailable, its corresponding Parquet file still exists with an empty schema, and the limitation is recorded in `data/reports/validation.json`.
